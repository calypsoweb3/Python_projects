# Student Management System

A simple command-line Student Management System built with Python.

# Features

- Add a student
- View all students
- Search for a student by ID
- Update student information
- Delete a student
- Input validation for IDs, names, ages, and courses

# Project Structure

Student_management/
│── main.py
│── student.py
│── student_manager.py
│── validator.py
│── README.md

# Requirements

- Python 3.10 or newer

# How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python main.py
