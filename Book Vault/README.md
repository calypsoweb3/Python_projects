📚 Book Vault

A simple command-line Library Management System built with Python using Object-Oriented Programming (OOP).

Features

- Add new books
- View all books
- Search for a book by ID
- Borrow available books
- Return borrowed books
- Delete books (only if they are not currently borrowed)
- Input validation for IDs, text, and publication year
- Interactive menu-driven interface

Technologies Used

- Python 3
- Object-Oriented Programming
- Dictionaries
- Functions
- Classes and Objects

2. Open the project folder.

3. Run the program.
